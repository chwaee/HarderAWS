# iam

Account password policy, a group with a constrained admin policy, an MFA deny policy on that group, a support role, and an SCP document that is output only.

CIS AWS Foundations Benchmark v3.0.0 controls 1.8, 1.9, 1.10, 1.15, 1.16, and 1.17.

AWS IAM has no password-lockout attribute. Failed-attempt lockout is not created here.
